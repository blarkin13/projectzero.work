# Project Zero guide editorial standard

The public guides exist to help readers build and operate digital businesses, acquire relevant organic search traffic, and generate eligible affiliate income. These objectives apply to new guides and existing-guide maintenance; useful, accurate content and reader trust come first.

## Content requirements

- Target a distinct, useful search intent: a buyer comparison, provider overview, troubleshooting question or task-specific how-to. Avoid near-duplicate keyword pages and claims of testing that did not happen.
- Every provider guide should explain product fit, setup, ongoing cost drivers, operational verification and common problems. Expand when there is more meaningful material, not simply to inflate word count.
- Each how-to should include prerequisites, a specific ordered sequence, concrete examples where appropriate, verification, troubleshooting and links to authoritative documentation. Retain existing canonical URLs.
- Comparison articles should compare actual capabilities, responsibilities, realistic cost scenarios and limitations, not rank by commission.
- Confirm volatile prices, plans, eligibility and technical interfaces against official documentation. Clearly label examples, old pricing and any unverified assumptions. Update materially changed content rather than inventing review dates.

## Discoverability and conversion

- Use one descriptive page title and H1, a useful unique description, canonical URL, crawlable internal links and appropriate visible-content structured data. List every indexable guide in the generated guide sitemap, which feeds the central public sitemap.
- Cross-link how-tos, related comparisons and provider guides where relevant. Make the how-to library reachable from navigation and the homepage. Use relevant purchase/signup calls to action only after explaining the decision.
- Use only verified, owner-approved affiliate URLs and permitted traffic sources. Disclose compensation immediately adjacent to each tracked link, mark it rel="sponsored", keep ordinary official pricing links, and never fabricate commissions, referrals or rankings.
- Shopify is the verified active link in current source. Add other partners only after confirming their accepted terms and exact tracked link. Do not represent an application as approval.
- Track affiliate-link clicks separately from general outbound clicks only under the existing opt-in analytics policy. Evaluate Search Console impressions/clicks, landing-page engagement, outbound affiliate clicks and actual partner-reported conversions; clicks are not commissions.

## Release and maintenance

Run repository checks and test sitemap URLs, canonical metadata, internal links, disclosure placement, responsive content and the absence of tracked links on unrelated pages. Publish to the existing guides Worker through the authorized release procedure. Verify the actual live pages, including the central sitemap. Record deployment blockers honestly. Never place secrets or private customer data in guides.
